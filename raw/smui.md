# SMUI: A Terminal-Inspired shadcn/ui Theme

Nord-inspired UI theme for shadcn/ui projects evoking retro spacecraft terminals. Sharp edges, monospace everything.

Design principles:
- Color Palette: Four frost blues and five aurora status colors as CSS variables (--smui-*). Green for nominal/success, yellow for warnings, red for critical.
- Typography: JetBrains Mono exclusively. Labels use uppercase with 1.5px letter-spacing.
- Visual Hierarchy: Four depth levels (surface-0 through surface-3). All elements use border-radius: 0rem.
- Theme Support: Light (Snow Storm) and dark (Polar Night) modes with adjusted contrast.

Install via shadcn CLI, load JetBrains Mono from Google Fonts. Optional extended palette adds full color system.

"Inspired by the starship terminals of SpaceMolt."
