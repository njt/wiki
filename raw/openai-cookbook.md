# OpenAI Cookbook

The OpenAI Cookbook is a collection of example code and guides for accomplishing common tasks with the OpenAI API. It is maintained by OpenAI and available both as a website (developers.openai.com/cookbook) and as an open-source GitHub repository (github.com/openai/openai-cookbook) under the MIT License.

Most code examples are written in Python, though the concepts can be applied in any language. Users need an OpenAI account and API key to run the examples.

## Topic Categories

The cookbook organizes content across nine topical areas:

1. **Agents** — /cookbook/topic/agents
2. **Evals** — /cookbook/topic/evals
3. **Multimodal** — /cookbook/topic/multimodal
4. **Text** — /cookbook/topic/text
5. **Guardrails** — /cookbook/topic/guardrails

8. **Codex** — /cookbook/topic/codex
9. **gpt-oss** — /cookbook/topic/gpt-oss

## Repository Structure

The GitHub repository (github.com/openai/openai-cookbook) contains:
- `examples/` — Primary example code and notebooks
- `articles/` — Written guides and explanations
- `images/` — Visual assets
- `AGENTS.md`, `CONTRIBUTING.md`, `LICENSE`, `README.md`, `authors.yaml`, `registry.yaml` — Standard repository metadata
