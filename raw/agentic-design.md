# Agentic Design

A free architecture catalog for AI builders. "Design AI agents with patterns you can inspect, compare and apply."

The site positions itself as "A connected catalog, not a list of buzzwords," claiming 280+ patterns, 280+ techniques, 900+ use cases, and 280+ interactive demos. Produced by KORTEXYA SAS, a French company.

## Core Workflow

A 4-step path from constraint to design:

1. **Frame the requirement** — reliability, latency, cost, or safety
2. **Compare relevant patterns** — mechanism, trade-offs, use cases
3. **Inspect implementation options** — techniques and interactive examples
4. **Practice and evaluate** — learning paths, Pro labs

## Catalog Contents

Patterns, model architectures, techniques, use cases, interactive demos, plus sections for MCP, LLM models, benchmarks, fine-tuning, AI inference, and a glossary.

## Learning Hub

"Structured learning journeys with theory, quizzes and practical challenges," each with a free opening chapter.

## Free vs. Pro Model

Thesis: "Start with the library. Pay when the tools save you work."

**Free**: browse the complete catalog, inspect use cases and demos, try opening chapters, ask the AI expert, run sandboxed code within a small daily allowance.

**Pro**: full learning journeys, Prompt Optimizer, Eval Lab, guided code challenges, red-team audits, workshop tools, managed AI usage, or bring-your-own Anthropic/OpenRouter API key.

## Pro Tools

The "Evaluate before you ship" section highlights the Prompt Optimizer, Eval Lab, and a "guided red-team workflow to examine behavior beyond the happy path."

## Design Philosophy

Emphasizes agent reliability in production: choosing "how an agent should reason, use tools and fail safely." A disclaimer notes scenario figures in examples are illustrative and "are not performance or compliance guarantees."
