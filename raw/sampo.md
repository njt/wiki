# Sampo: Changelog and Release Automation

Automate changelogs, versioning, and publishing -- even for monorepos across multiple package registries.

## Multi-Ecosystem Support
Rust (Crates.io), JavaScript/TypeScript (npm), Elixir (Hex), Python (PyPI), PHP (Packagist), with more planned.

## Core Components
- **sampo CLI**: Primary command-line interface for changesets and releases
- **sampo-core**: Foundational logic and shared utilities
- **sampo-github-bot**: GitHub App that reviews PRs and requests changeset submissions
- **sampo-github-action**: Automation for release and publishing pipeline

## Design Philosophy
Inspired by Changesets and Lerna but prioritizes Rust implementation and multi-ecosystem compatibility. Leverages Knope project's changeset parsing library.

Built by Bruits, a Rust-focused collective.
