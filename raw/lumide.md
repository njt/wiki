# Lumide

200ms cold start / 80MB idle. Native speed for agent-native development.

Crafted with Pure Flutter & Dart for people who want an IDE to feel like a desktop tool: fast startup, low memory use, and no Electron layer.

Download for macOS ~40 MB. Available for macOS, Windows, and Linux.
