# The Code-First Developer

Khalil Stemmler's article on the first phase of his "5 Phases of Craftship" framework. Part of a series on developer growth from code-first through best-practice-first, pattern-first, responsibility-first, to value-first.

## The 5 Phases of Craftship

1. Code-First
2. Best Practice-First
3. Pattern-First
4. Responsibility-First
5. Value-First

## The Code-First Developer

Has learned to code but has yet to learn to craft. The four pillars every developer needs: design, testing, architecture, and strategy — collectively aimed at serving the 3 roles (customers, developers, users) by creating either TimeGivenBack or TimeEnriched.

## The Expert Junior Developer Trap

Breadth-first learning keeps you stuck at the surface — years of experience but still asking beginner-level questions.

## The Value Differential

With GitHub Copilot and ChatGPT, the value of a single full-stack Pattern-First Developer with access to ChatGPT became greater than 5+ frontend developers combined. Low-skilled frontend and hyper-specialized developers are losing jobs.

## Burnout → Mastery

Burnout is when effort doesn't match fulfillment. The remedy: Mastery is recession-proof.

## Progression Steps

1. Shift focus to Responsibilities instead of code
2. Commit to becoming a Value-First developer (fullstack)
3. Build an information system end-to-end for a real human user
4. Zoom out to examine what your tools are really for
