## About the Book

The Elements of Code gives programmers a series of rules for writing software that future readers will understand. Changing requirements and an evolving world mean that programs must constantly be extended, updated, and re-written. In such an environment, chasing perfect software is a Sisyphean task. The goal, then, is not to be correct, it is to be correctable.

Writing comprehensible code is what allows us to be wrong in correctable ways.
