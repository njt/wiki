# AI Pricing

AI Pricing tracks live and historical per-token API pricing across major AI model providers including OpenAI, Anthropic, Google, DeepSeek, GLM, Qwen, MiniMax, Mistral, xAI, Groq, Fireworks, Together, DeepInfra, Cloudflare Workers AI, Novita, Cerebras, Nscale, DigitalOcean, and Kimi.

## Public API

Use the public JSON API to list providers, inspect canonical models, fetch current prices, discover valid price filters, and monitor recent price changes. The API does not require authentication for read-only endpoints.

## Glossary

Core terminology: a provider is an inference platform; a canonical model is the normalized model identity; an offer is a provider-specific billing surface; a price dimension is a metric such as input tokens, cached input tokens, or output tokens. See the terminology glossary in the markdown mirror.
