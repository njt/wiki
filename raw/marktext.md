# MarkText: Markdown Editor

Open-source markdown editor emphasizing simplicity and performance. Provides a distraction-free writing environment with real-time preview.

## Key Features
- Real-time preview (WYSIWYG) with clean, simple interface
- CommonMark, GitHub Flavored Markdown, and selective Pandoc markdown support
- Math expressions via KaTeX, front matter support, emoji integration
- Source code, typewriter, and focus editing modes
- Export to HTML and PDF
- Multiple themes (Cadmium Light, Material Dark, etc.)
- Clipboard image pasting

## Supported Platforms
- macOS (DMG or Homebrew Cask)
- Windows (setup wizard, Chocolatey, or Winget)
- Linux (multiple distributions)

## Technical Stack
JavaScript (69.6%), Vue (15.2%), CSS (15.0%). Built on Electron. MIT licensed. 56,000+ GitHub stars.
