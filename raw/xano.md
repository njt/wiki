# Xano

Xano is a backend-as-a-service (BaaS) platform that combines AI, visual tools, and code into a unified backend builder. It provides a managed PostgreSQL database, no-code API builder, visual business logic engine, built-in authentication (JWT, RBAC), and environment management — all positioned as "build a backend, not a black box."

## How It Works

Xano promotes a four-step workflow: BUILD (AI generates APIs, databases, workflows), REVIEW (visual rendering of all generated logic), TEST (infrastructure-level sandbox isolation), SHIP (production deployment without assembling separate tools).

## Key Features

- **Visual Logic Builder**: Build visually, write code, or mix both — kept in sync.
- **AI-Assisted Building**: Describe needs, AI constructs backend. Connects via Developer MCP and CLI.
- **Managed Postgres Database**: "No migrations, no DevOps."
- **No-Code API Builder**: Instant REST APIs with authentication, rate limiting, custom logic.
- **Built-in Authentication**: Sign-up, login, JWT tokens, RBAC.
- **Observability & Monitoring**: Request tracing, performance dashboards, audit logs.
- **Environment Management**: Branch, test, promote through environments.
- **CI/CD**: Continuous integration and deployment capabilities.

## Competitive Positioning

Direct comparison with Supabase and Firebase. Claims advantages: visual workflows (vs. "raw code only"), no setup (vs. "manual setup"), built-in logic engine (vs. "DIY logic"), easy to modify (vs. "code-heavy editing"), visual transparency (vs. "logs only").
