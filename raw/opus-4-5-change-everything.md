Burke Holland's field report of building four complete applications with Claude Opus 4.5 in VS Code — a Windows image conversion utility, a screen recording/editing app, an AI-powered Facebook posting utility for his wife's business, and an order tracking/routing app — nearly entirely by prompting. Opus 4.5 handled dotnet CLI builds, Firebase provisioning, Google auth email integration, and auto-grepped cloud function logs for errors. Burke shares his full "AI-first coding agent" prompt and a refactoring/security audit prompt. The emotional payload: a seasoned developer admitting he can't tell whether he's exhilarated or depressed that the craft he spent a lifetime learning is now trivial for a computer.
