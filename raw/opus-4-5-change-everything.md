Burke Holland describes building four complete applications almost entirely with Claude Opus 4.5 in VS Code with GitHub Copilot and Context7 MCP. The projects: a Windows image conversion utility, a screen recording/editing app (RecordMe), an AI-powered Facebook posting utility for his wife's business, and an order tracking/routing app. He contrasts Opus 4.5 with prior AI agent experience -- previously "spaghetti code" and "destructive chat sessions" -- calling Opus 4.5 "the model that we were promised."

The post includes Burke's full custom Copilot agent prompt, which instructs the model to "assume all code will be written and maintained by LLMs, not humans" and lays out nine coding principles covering structure, architecture, functions, naming, logging, regenerability, platform use, modifications, and quality. He also shares secondary prompts for refactoring and security auditing.

Burke addresses code quality concerns directly: "I'm less worried that a human needs to read the code, because I'm genuinely not sure that they do." On security, he rates confidence at ~80%, calling it "too damn low." The post closes with ambivalence about the craft of software engineering becoming "trivial for a computer" and advice to "stop waiting to have all the answers" and just build things.
