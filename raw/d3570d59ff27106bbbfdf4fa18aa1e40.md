Jesse (creator of Superpowers) argues that the frontier of agentic coding has moved past models and into harness design: the biggest wins now come from opinionated tooling — skill triggering, compaction, subagent task decomposition, and "AI colleagues" with jobs and identities — rather than raw model capability, and the economics are flipping so fast (he ran 100 billion tokens of DeepSeek 4.1 Flash in a month on flat-rate concurrent-request billing; Opus 4.5-class intelligence now runs locally on a 64GB MacBook) that the frontier-lab-per-token model will give way to a split of a few expensive frontier calls plus cheap local/open-weights workhorses. If you disagree, you'd have to argue that harness-level craft is a transitional artifact that model improvements will absorb — a claim he directly rebuts by noting Superpowers is still ahead of frontier-lab internal state of the art a year after shipping.

Key points

Superpowers endures by separating two things harnesses conflate. Claude Code's plan mode merged "help the human figure out their intent" with "the exact set of technical tasks to be implemented" — two distinct management processes. Superpowers keeps them separate, which is why the full flow is "way more expensive" than letting the model yolo it but repeatedly evals as "much closer to bug free." Version 7 now asks up front whether a change is bounded enough to skip the full flow.

Skill triggering is a design problem, not a prompting problem. Superpowers' original skill format had a separate "when to use" line the model saw instead of the description — because when models can read a description and think "I know how to do a code review," they skip loading the skill to save context. Anthropic adopted "about a dozen" of his suggestions (e.g., name skills in active voice) three days after reviewing his feedback.

Better bug-finding broke convergence. Review loops that used to settle in two or three rounds now never stop: "The OpenAI models are obsessed with edge cases." His fixes: if seven turns don't converge, the work is too big — decompose it; if only low-severity issues remain, write them out and merge with fast-follows.

Flat-rate inference changes behavior qualitatively. Going from metered five-hour windows to "I can just do things" let him process 30 years of personal email into Wikipedia-style contact articles — recommendations, life events, kids' names, nightshade allergies — the CRM data you actually want.

Evener is a deliberately non-pluggable harness. Provider-agnostic (multiplexing models, not harnesses), supporting Claude Code and Codex plugins and marketplaces, but opinionated rather than "PI style, where everything's a plugin." Distinctive features: subagents receive task lists with per-task effort levels and injected prompts; the model controls its own compaction via a tool that includes "write yourself a letter of all the important stuff you want to remember after"; a "Doctor" agent debugs the harness itself by examining failed tool calls.

AI colleagues with roles, not just tasks. A bespoke long-horizon multiplayer harness (the coming "Superpowers Z" product) runs a PM (Cadence) and AI devs (Ada) who hold team meetings, assign work to each other, roll security releases after finding exposed API keys three times in a month, and run blameless postmortems — in one case shipping something Jesse told them not to ship in Slack, because the Claude Code instance he addressed wasn't in the channel.

"Proving it works with a movie" — have the agent screen-record a demonstration of the finished feature; his first run produced v34.mp4 because the first 33 proof cycles found bugs the tests missed.

Tools, practices, and methodologies

Superpowers — open-source skill system for coding agents (300K stars, 12th project ever); use its full brainstorm→plan→execute flow for unbounded work, skip it for bounded changes; skills should trigger proactively, never manually.

Evener — his open-source, provider-agnostic coding agent harness; use it to multiplex models across providers, dispatch subagents with structured task lists, and let the model self-compact with a "letter to yourself" memory tool.

Clearance — his open-source markdown browser for reading agent output.

RoboRev (Wes McKinney) — AI code review with post-commit git hooks; run it in the background on every commit, ignore reviews until branch end, then handle them in one batch.

Kata / Agents View / Message Vault — McKinney's local-first agent issue tracker, cross-harness transcript search with embeddings, and a read-only database of Gmail/WhatsApp/iMessage/Slack for agents to query.

DeepSeek 4.1 Flash on concurrent-request billing — flat-rate inference for bulk work like email mining; reserve frontier models for hard questions.

Qwen (local open weights) — "Quinn 3827B" on a 64GB MacBook at 30+ TPS, roughly Opus 4.5-level, for workaday tasks at electricity cost.

Proving-it-works-with-a-movie — end-of-task screen recording demonstrating the feature works end to end.

Agent school — build role skills by asking "what would it take to get a competent human from zero to expert in 18 months?" and converting that into skills.

Unanswered questions and omissions

Security of autonomous colleagues is raised, not solved. The PM found exposed API keys three times in a month and shipped against an explicit instruction; Jesse never addresses permissioning, blast radius, or guardrails for agents with accounts and identities — the obvious elephant in the room for Superpowers Z.

No numbers on the cost/quality tradeoff. He says the full Superpowers flow is "way more expensive" and "much closer to bug free" but never quantifies either side.

The per-provider build step question is deferred. He admits he's "not convinced that we'll be able to avoid it forever" but offers no path forward.

The home-directory loss gets no process lesson beyond "I wasn't supervising tightly enough" — what supervision would have caught it?

Privacy of Message Vault-style siphoning (Gmail, WhatsApp, Slack into agent-queryable databases) goes unexamined.

Pricing, availability, and architecture of Superpowers Z are teased but unspecified.
