# Shaper: SQL-Driven Data Dashboards (DuckDB)

## Main Purpose
Open-source, self-hosted analytics platform that enables building data visualization dashboards using SQL queries, powered by DuckDB.

## Key Features

**Data Visualization:**
- SQL-first approach with AI readiness
- Git-based workflow support
- Multi-source data querying

**Embedded Analytics:**
- White-labeling and custom styling
- Row-level security via JWT tokens
- JavaScript and React SDKs (no iFrame required)

**Automated Reporting:**
- Generate reports in PDF, PNG, CSV, and Excel formats
- Scheduled alerts and automated reporting
- Password-protected shareable links

## Usage
Create interactive dashboards by writing SQL statements with special casting syntax to define visualization types (e.g., `::BARCHART_STACKED`, `::XAXIS`).
