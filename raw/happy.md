# Happy - Mobile and Web Client for Claude Code & Codex

Cross-platform client enabling users to access Claude Code and Codex from mobile devices and web browsers with end-to-end encryption and seamless device switching.

## Key Features
- Mobile access: Control Claude Code and Codex from iOS and Android apps
- Web interface at app.happy.engineering
- Device switching: Instantly transfer control between phone and desktop with a single keypress
- End-to-end encryption: Code remains encrypted across all devices
- Push notifications: Real-time alerts for permissions and errors
- Open source: Fully auditable codebase with no telemetry

## Core Components
1. **Happy App** - Web UI and mobile client (built with Expo)
2. **Happy CLI** - Command-line wrapper for Claude Code and Codex
3. **Happy Agent** - Remote session management and monitoring
4. **Happy Server** - Backend infrastructure for encrypted synchronization

## How It Works
Users run `happy` instead of `claude` directly. The wrapper enables remote sessions accessible via mobile apps, allowing monitoring and control of AI coding agents away from desktop computers.
