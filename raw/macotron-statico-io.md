# Macotron does everything.

`brew install statico/tap/macotron`

Free and open source. Built with Swift and QuickJS.

**Beta.** Macotron goes 1.0 when I, the author, consider it stable. Until then, expect things to move around.

## Capabilities

## Plugins

          The catalog ships 73 built-in plugins. First launch copies the ones you
          pick into `plugins/`. Macotron writes an `AGENTS.md`
          next to them so a coding agent already knows the API. Open a file in
          the finder to read the script this site ships.

        ## Host API

Everything hangs off `macotron.*`. Apple-shipped tools only. Plugins call these namespaces to tile windows, read sensors, and talk to models.
