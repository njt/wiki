One relational claim: Grist beats spreadsheets by linking data, not copying it

This onboarding webinar argues that Grist's core advantage over traditional spreadsheets is relational structure: instead of repeating data across tables, users should create reference columns that point back to a single source of truth, then layer on linked widgets and summary tables to build lightweight dashboards. Natalie, a Grist customer engineer, demonstrates that once data is normalized — "you never want data to repeat" — updates propagate everywhere automatically, widgets can be linked so selecting one record filters another, and formulas apply to entire columns rather than dragged cells. The pitch matters because it reframes Grist not as a spreadsheet clone but as a database tool accessible to spreadsheet users, with access controls at team, workspace, and document levels making it viable for collaborative team work.

Key points

Personal vs. team sites trip up new users. Every account has a personal site (marked by your name in the upper left); team sites are for shared work. The most common beginner mistake is creating a document in one site while viewing the other — "Where did my document go?" The fix: duplicate the document and select the correct organization and workspace.

Access inherits downward by default. Team-level access (owner, editor, viewer, or none) flows to every workspace and document. You can break inheritance at the workspace level (e.g., restrict a marketing workspace to just the marketing team) and again at the document level, where you can still manually add people outside the workspace.

Free collaborators are capped at two per document on personal documents, but they're swappable — remove one, add another — and the UI shows your count.

Reference columns are the star feature. Converting a text column (e.g., owner names in a dogs table) to a reference type links each record to the matching row in another table. Update the owner's name or phone once, and every referencing table reflects it. Lookups can pull fields (like phone number) from the referenced record into formula columns.

Linked widgets create dashboards. Because the reference column establishes the relationship, adding a card widget "selected by" the dogs table shows the selected dog's owner details live — letting you hide redundant columns from the table view.

Summary tables are Grist's pivot tables. Group by any column (e.g., location) for counts and totals, and use "select by" to make clicking a summary row filter the underlying table. New rows added while a location is selected auto-assign to that location.

Formulas apply to the whole column — no dragging cells — and you get Excel-like functions, Grist-specific functions, and the full Python standard library. Typing "=" in any column converts it to a formula column.

Safety nets abound: Document History snapshots (with compare/replace options), a 30-day trash, an Activity log showing the last ~100 changes with author and timestamp, and "Work on a copy" for risk-free formula testing.

Tools, practices, and methodologies

Personal vs. team sites: Separate spaces for private vs. collaborative documents; switch via the upper-left name or profile menu.

Access inheritance model: Set defaults at team level, override at workspace and document levels via the three-dot "manage users" menus; always click the green confirm to save.

Workspaces: Folders within a team site, created via the "add new" button, each with their own access rules.

Duplicate document / Work on a copy: Move a document between sites by duplicating (then deleting the original), or test changes in an unsaved copy and optionally "replace the original."

Document History snapshots: Restore, compare, or replace versions; recover deleted formulas by copying from a snapshot.

Reference columns + lookups: Convert a column to reference type, then pull related fields via lookup formula columns; update data in one place only.

Linked widgets (card widget + select by): Build dashboards where selecting a record in one widget filters another.

Summary tables: Click the green summation icon, choose group-by columns, and link them to detail tables via "select by."

Filter buttons (pinned filters): Save filters as buttons; unpinned filters reset on page refresh — handy for temporary views.

AI assistant: Plain-English formula help; sends document structure and data to OpenAI, so try it on a sample document with fake data first.

Import from Excel/Google Drive/URL: Each sheet imports as a new page/table; skip unneeded tabs.

Resources: Template gallery (three templates include step-by-step "how to" tutorials), Grist Basics interactive tutorial, Help Center (Function Reference Guide, FAQ), community forum, and the trash (30-day retention).
