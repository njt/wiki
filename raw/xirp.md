## What Xirp provides

## Parallel coding sessions

Run Claude Code, Codex, or Gemini in persistent terminal sessions and switch
between them without losing state.

## Optional Portal context

Connect Spotify Portal to give agents access to Workspace wiki pages,
catalog entities, resources, records, members, and prior sessions.

## Project isolation

Create a separate Git worktree for each task so agents can work in parallel
without changing the same checkout.

## One control surface

Manage terminals, Git changes, files, rules, skills, session status, and
layouts from one app.

## Use Xirp on its own

Xirp can run general sessions without a project and project sessions against folders on your Mac. Portal is not required for local projects, persistent terminals, Git worktrees, files, rules, skills, or grid view. Xirp does not replace your coding agent or source control provider. You continue to authenticate and configure each coding agent through its native CLI.## Add Portal features

Connecting Portal adds shared organizational context and catalog-based workflows:- Portal holds context in the Software Catalog and Workspaces.
- Xirp runs coding agents against repositories on your Mac.
- A session launched from a catalog entity or Portal Workspace can receive relevant context through MCP.
- You can upload a completed Workspace session for teammates and future agents.

## Current beta scope

- macOS only
- Claude Code, Codex, and Gemini coding agents
- Optional Portal connection for catalog and Workspace features
- Manual session upload for Workspace-launched sessions
