# UI style guides

This is a collection of preserved UI style guides a.k.a. interface guidelines from various companies, starting from the early 1980s and continuing to today.

- 
    ### Amiga(Commodore) Amiga was a multimedia personal computer particularly popular in the 1980s and 1990s in Europe. Its GUI was called Workbench. 
-         
      Amiga User Interface Style Guide

- 
    ### AndroidAndroid is a mobile operating system and a rival to iOS. The first style guide I could locate was in 2012. 
-         
      Android Design
-         
      Material Design v1
-         
      Material Design v2
-         
      Design for Android

- 
    ### BlackBerryBlackBerry was a beleagured maker of mobile handsets. 
-         
      BlackBerry Wireless Handheld User Interface Style Guide
-         
      BlackBerry PlayBook Tablet UI Guidelines
-         
      BlackBerry Smartphones UI Guidelines
-         
      BlackBerry 10 UI Guidelines

    ### CDECommon Desktop Environment (CDE) is a desktop environment for Unix machines, using (and eventually merging with) OSF/Motif widgets. 
-         
      OSF/Motif Style Guide
-         
      Common Desktop Environment: Style Guide and Certification Checklist

- 
        ### CUACommon User Access (CUA) is a late 1980s standard for user interfaces that influenced Windows and OS/2. 
-         
        System Application Architecture: Common User Access
-         
        Object-Oriented Interface Design: IBM Common User Access Guidelines

- 
    ### GEM/TOSGraphics Environment Manager (GEM) is a 1980s operating system/GUI. It was well-known by users of the Atari ST computers, known in these circles as TOS.

      GEM User Interface Guidelines

      The documentation for TOS
