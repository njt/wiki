# Self-Hosted LLMs

A calculator/reference site for mapping hardware to LLM performance. Answer the question: "If I have this GPU/CPU, what models can I run and at what speed?" Useful for anyone considering self-hosted inference rather than API calls.

This fills a practical gap in the self-hosting ecosystem. Most model cards list VRAM requirements but not real-world token generation rates on specific hardware. Knowing that a model *fits* on your GPU is different from knowing it will generate tokens fast enough to be usable.

The "if I have X, what can I do with it?" framing is the right question. Most people start with hardware constraints, not model preferences.
