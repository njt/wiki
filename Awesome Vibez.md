## Critical Analysis

The interesting pattern is that nearly everyone in this group builds tools *around* agents rather than agents themselves. The infrastructure layer (session viewers, sandboxing, orchestration, memory systems) is where the practical problems live. The agent harness is solved (Claude Code, Codex, etc.); it's the workflow around the harness that's still being figured out.

Generated from WhatsApp chat exports in March 2026. The informal, community-driven nature of this list means it captures what practitioners actually use, not what gets the most GitHub stars.
