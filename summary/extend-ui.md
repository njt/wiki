# Extend UI

Open source React component library for document-intensive applications. Tagline: "Open source UI kit for modern document apps."

GitHub: https://github.com/extend-hq/ui (560 stars)

## Components

| Component | Description |
|---|---|
| PDF Viewer | Render and interact with PDF documents |
| Document Splits | Split documents into named sections with page ranges |
| XLSX Viewer | Render Excel/spreadsheet files |
| File System | File browsing and management interface |
| DOCX Viewer | Render Word documents |
| File Thumbnail | Thumbnail previews for multiple document types (Image, PDF, DOCX, XLSX) |
| Schema Builder | Multi-level JSON schema editor with nested property definitions |

## Layout Blocks

Larger composed examples:
- Layout Blocks — full-page document workspace layouts
- Bounding Box Citations — highlight and cite specific regions of documents
- File System — full file browser block
- XLSX Viewer — Excel document with split panes
- File Upload — PDF dropzone with drag-and-drop
- DOCX Editor — editable Word document block
- E-Signature — e-signature capture and placement

## Positioning

"React components for PDF, DOCX, XLSX, and CSV viewers, with bounding box citations, file upload, e-signing, and more. Ready to drop into user-facing flows, agents, or internal tools."

## Design

Light and dark theme support. Site navigation includes Docs, Components, and Blocks sections with search and layout/theme toggles.
