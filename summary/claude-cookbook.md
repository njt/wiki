The Claude Cookbook is Anthropic's canonical collection of 84 practical guides and code examples for using Claude effectively. Entries span from August 2023 to June 2026, organized newest-first.

Major categories include Agent Patterns (12 entries covering orchestrator-workers, multi-agent coordination, ReAct agents, and context engineering), the Claude Agent SDK (7 entries for one-liner research agents, SRE agents, vulnerability detection, and migration from OpenAI's SDK), and Claude Managed Agents (7 entries covering production setup, prompt versioning, SRE incident response, and Slack bot integration). The Tools section covers programmatic tool calling, tool search with embeddings, automatic context compaction, and parallel tool calls. RAG & Retrieval entries cover contextual retrieval, text-to-SQL, knowledge graph construction, and citations. Multimodal entries address vision best practices, document transcription, and working with charts and slide decks.

Other sections cover Evals, Extended Thinking, Skills (custom and financial), Observability, Fine-Tuning, third-party Integrations (ElevenLabs, Deepgram, Wolfram Alpha, LangChain, LlamaIndex, Pinecone), and Responses (prompt caching, batch processing, speculative caching, metaprompting). Contributions are accepted via the claude-cookbooks GitHub repo.
