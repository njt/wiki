A RAGFlow-team position paper arguing that retrieval has become a harness problem, not an index problem. A search harness with only BM25 and grep (answering model MiniMax M3) already reaches 85% on BrowseComp-Plus and 91% on FRAMES with no vector index at all — adding a dense leg *lowered* accuracy in their runs.

With accuracy saturated, the paper pivots to a second claim: the missing layer is **knowledge compilation** — a query-independent ingestion pipeline (parse → chunk → enrich → validate → assemble → register) that produces typed artifacts with verbatim provenance: navigation trees whose leaves are claim–evidence pairs, entity graphs, ontologies, wikis, timelines, mind maps, session memory.

The headline negative result: structural artifacts (RAPTOR summary trees, PageIndex outlines, LLM wikis, entity–relation graphs) gave **no detectable accuracy gain** under a competent harness, and a PageIndex outline actually degraded at FRAMES scale (a 95%-correct routing level compounds to ~75% end-to-end success; a confident wrong branch is worse than open search).

The positive result is cost, not accuracy: claim–evidence substitution cuts total query tokens by 91% when the compiled evidence suffices and adds 1.9% when it doesn't — a 38% FRAMES average against a 2% break-even sufficiency rate. The catch: substitution buys tokens with turns, roughly tripling latency on the paired subset. A decision gate cuts latency from 140s to 30s.

The harness side is a five-station disciplined loop (capability check → evidence prefetch → evidence gate → tool loop → deterministic close) with invariants a model cannot be trusted to enforce itself: evidence before thought, discard on insufficiency, tool gating, budgeted calls, citations assigned at delivery, guaranteed close. Tools are organized by the failure they remove, and a "zero-hit" result is treated as a tool property, never as evidence of corpus silence.

Deployment value of ontologies/graphs/wikis/timelines is reported on a separate ledger — which the authors candidly publish with an empty result column: "every row is reported as no measured effect." The destination concept is the **agent-native database**: a store that hands the agent compiled, governed context instead of a ranked list of passages.
