# Mist: Collaborative Markdown Editor

"Share and edit Markdown together, quickly."

## Key Features
- Real-time collaborative editing of Markdown documents
- Simple file upload via drag-and-drop
- Command-line access: `curl https://mist.inanimate.tech/new -T file.md`
- Browser-based, no installation required

## Status
Work in progress. MIT licensed. Bug tracking on GitHub.

## Use Case
Quick, lightweight collaborative Markdown editing -- like Google Docs but for Markdown. No accounts, no vaults, no setup. Just share and edit.
