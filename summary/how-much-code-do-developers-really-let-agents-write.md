JetBrains reports on its Developer Ecosystem Survey 2026 (15,000+ professional developers, May–July 2026), asking what share of last month's work code was fully agent-generated, AI-assisted, or fully manual. On average developers report ~47% fully agent-generated, ~38% AI-assisted, ~27% manual — but the averages hide a bimodal reality: over half write less than 20% of their code manually, yet only ~22% rely on agents for over 80% of their code.

Adoption splits sharply by seniority, tool, language, and region. A quarter of senior developers are heavily agentic versus a smaller share of juniors; 32% of Claude Code users and 42% of Codex users generate over 80% of code with agents, which JetBrains reads as Claude Code having gone mainstream while Codex retains advanced users. Go/JS/TS developers lead (54–55% agent-generated); C/C++ developers lag (38% manual). East Asia leads regions at 32–35% heavy-agentic versus ~16% in Europe and the UK.

Cluster analysis yields three segments: agentic coders (~31%), AI-assisted coders (~47%), and manual coders (~23%). The headline: purely manual coding is disappearing fast, but full agentic workflows remain a minority practice — the "100% of my code is written by agents" claim describes a loud minority, not the median developer.
