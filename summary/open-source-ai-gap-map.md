Simon Willison's link post about Current AI's Gap Map, an interactive index of the open-source AI ecosystem. Current AI is "a global partnership building a public option for AI", founded as a non-profit at the AI Action Summit in Paris in February 2025 and backed by $400m in committed capital. The Gap Map v0.1 details 421 products in depth: 266 software tools and libraries, 85 models, 50 datasets, and 20 hardware projects, produced by 228 organizations. Products are organized into 14 categories across 3 layers of the stack (model components, product/UX, and infrastructure). The remaining 24,400 artifacts constitute the uncategorized long tail.

Simon is more excited about the underlying data than the map itself — released under an MIT license in the currentai-org/os-ai-map GitHub repository: 1,184 YAML files plus notebooks, schemas, and other scripts. He uses Datasette Lite to explore a CSV of 16,185 GitHub repos the project is tracking.
