End-to-end environment for agentic development. Terminals, context files, and running code arranged on an infinite canvas. Native desktop app for macOS, Windows, and Linux.

Stack: Electron 40, React 19, Tailwind CSS 4, xterm.js (terminal emulation with persistent node-pty sidecar), Monaco Editor (code editing), BlockNote/TipTap (rich text markdown), D3 (force-directed graph visualization).

Key concepts: Navigator sidebar with file tree and workspace switcher. Canvas as infinite pan-and-zoom surface. Tiles as live views bound to files or PTY sessions. File tiles update when disk changes; terminal tiles persist independently.

All data stored locally on disk. No accounts required. Multiple workspaces supported.
