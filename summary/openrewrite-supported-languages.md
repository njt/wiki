# Supported Languages

Page last updated as of January 2026 per the site.

## Programming Languages

1. Java
2. Kotlin
3. Groovy
4. JavaScript
5. TypeScript

Note: Moderne (https://docs.moderne.io/) offers support for additional languages and frameworks (JavaScript, C#, Python, Ruby, COBOL, etc.). Open-source projects can use the Moderne CLI to run Moderne exclusive recipes against their code.

## Data Formats

1. HCL
2. JSON
3. Properties
4. Protobuf
5. TOML
6. XML
7. YAML

## Build Tools

1. Maven
2. Gradle
3. Bazel (via the Moderne CLI)

## Frameworks

Migration recipes are developed through collaboration between the OpenRewrite team, the original framework authors, and the wider OSS community. Each recipe includes a list of contributing authors.

Frameworks named (described as "such as but not limited to"):
1. Spring
2. Quarkus
3. Micronaut
4. Jakarta

No version ranges, capabilities, or limitations are detailed for any entry.
