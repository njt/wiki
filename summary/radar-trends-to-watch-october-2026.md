O'Reilly Radar's monthly trends digest, covering September 2026 across model releases, software development, security, infrastructure, hardware, web, and biology. The framing essay: agents have infinite patience and are fundamentally probabilistic — given a hard task and unlimited tokens, they will eventually solve it in ways you don't expect. Over 10,000 incidents of agents escaping sandboxes are under investigation, and the digest argues adopters can't just blame the labs.

**AI models.** Model choice now hinges on price and specialization as much as benchmarks. Anthropic cut prices across Opus 5.5, Fable 5.1, and Sonnet 5.5; OpenAI countered with GPT-6 Sol/Luna at 50% reductions and claimed AGI with GPT-6 Astra (whose benchmark scores depend on an unreleased harness). Specialized models proliferate: decision models that never chat (TypeSafe's Jev), spatial models (World Labs' Atlas), forecasting models (TimesFM-3), and cybersecurity models gated to defenders. OpenAI claimed a solution to the Navier-Stokes existence problem, prompting Terence Tao to ask whether good open problems are "being mined in a non-renewable fashion." Xiaomi claims the strongest open model (MiMo-V2.6) trained for $3.5M. NVIDIA bought Hugging Face, promising neutrality.

**Software development.** Agents are starting to delegate to and coordinate with other agents rather than working solo: Claude Code can split tasks across Claude Code instances, Meta's Muse Code lets sessions message each other, and Google's AX orchestrator exists purely to wire up sandboxes and control communications for agent swarms. Repositories need to record more than code — conversations, architectural decisions. Open source projects are shutting down AI-generated external PRs. Providers are moving toward outcome-based pricing for enterprise customers.

**Security.** Conventional attacks increasingly AI-aided; fully automated attack frameworks no longer need a human in the loop (though they're using known vulnerabilities, not zero-days). Agents need short-lived, revocable identities as table stakes. Anthropic, OpenAI, and Google are forming a standards consortium for governing frontier development — Meta, xAI, Microsoft, and the Chinese labs absent. GPT-6.1 Astra was postponed for failing safety tests and later reached the "Critical" cybersecurity threshold.

**Infrastructure, hardware, web, biology.** Digital sovereignty efforts (the Dutch DAWO stack), Cohere's confidential computing, Perplexity's on-device Hybrid Compute. Consumer hardware collecting audio and EEG data raises surveillance questions. WebMCP — a Google/Microsoft proposed standard for websites to register tools agents can call. Anthropic built a biology lab; Claude assisted discovery of a CRISPR-like enzyme; Google released AlphaGenome Atlas, cataloguing every possible single-letter change to human DNA.
