## Product Description

Thunderbolt is an open-source, cross-platform AI client designed for enterprise use, emphasizing user control and data sovereignty. It functions as an extensible AI interface enabling users to conduct research, organize files, search email, and interact with AI agents through a unified platform while maintaining complete infrastructure control.

## Key Features

- **Control Your Data:** Self-host on your infrastructure or let us help you deploy. Data remains under user management.
- **Choose Any Agent:** Connect any ACP-compatible agent or any model with an OpenAI-compatible API (Claude, Codex, DeepSeek, etc.)
- **Built for Enterprise:** Native apps across web, desktop (Windows/macOS/Linux), and mobile (iOS/Android)
- **MCP Integration:** Model Context Protocol support
- **Custom Integrations:** Full API access
- **Automations:** Reusable workflow automation
