Television is a desktop/browser application pitched as "the missing GUI for personal agents." It gives a human and their agent a shared visual workspace built around *artifacts* — cards, interactive views, or external web pages that the agent pins so important output isn't lost in the chat scroll.

The mechanics, as described on the landing page: any agent that can run commands and write files can drive Television. Artifacts persist and can be revisited and organized over time, collected into *channels* — persistent, arranged spaces for ongoing work. The product also ships *skills*: reusable instructions for creating interfaces, adaptable and shareable.

The landing page is thin — mostly a repeated tagline, three feature blurbs, and install pointers (Mac app, or browser for non-Mac users, installed by your agent). But the pitch itself is a distinct position in agent UX: instead of the chat transcript being the only surface, the agent writes to a durable visual space the human curates.
