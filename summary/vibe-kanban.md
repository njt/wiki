# Vibe Kanban

## Main Purpose
Development tool for planning and reviewing code generated by AI coding agents. Provides kanban boards for managing agent-generated work, with built-in code review and workspace execution.

## Key Features

**Planning & Management**
- Kanban board for creating, prioritizing, and assigning issues
- Support for both private and team-based planning workflows

**Workspace Execution**
- Dedicated workspaces where coding agents operate with their own branch, terminal, and dev server
- Supports 10+ coding agents: Claude Code, Codex, Gemini CLI, GitHub Copilot, Amp, Cursor, OpenCode, Droid, CCR, Qwen Code

**Code Review & Collaboration**
- Built-in diff reviewing with inline commenting
- Pull request creation with AI-generated descriptions
- GitHub integration for PR review and merging

**Development Preview**
- Integrated browser with developer tools
- Inspect mode and device emulation

## Project Status
**Vibe Kanban is sunsetting.** (Per announcement on the project page.)

## Technical Stack
- **Backend**: Rust (50.3%)
- **Frontend**: TypeScript (46.0%), JavaScript (1.5%)
- **Additional**: CSS, HTML, PLpgSQL

`npx vibe-kanban` — requires prior authentication with a supported coding agent.
