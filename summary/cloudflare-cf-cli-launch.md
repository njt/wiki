Cloudflare launches **cf**, an open-beta CLI intended to replace Wrangler as the primary interface to the Cloudflare platform, built explicitly for agent users. The trigger is usage data: agents went from single-digit percentages of Wrangler use to 48% within a year, and agents use nearly twice as many distinct commands per day as humans.

cf replaces Wrangler's ~280 hand-built command paths with over 3,000 operations generated by the new **Forge** pipeline directly from the OpenAPI schemas that already power Cloudflare's API docs and SDKs. Because agents have no prior training-data familiarity with cf, the post argues that a clean break beats incrementally changing Wrangler — a fresh tool with agent-first defaults is less confusing than asking an agent to reconcile two learned versions of a familiar tool.

The agent-first design decisions: JSON is the default output (condensed for agents, pretty-printed for humans) instead of human tables plus `--json` + `jq` workarounds; `cf cli search` provides natural-language command discovery over the 3,000-operation surface, injected to the agent on first `--help`; and configuration moves from TOML/JSONC to `cloudflare.config.ts`, a TypeScript config with LSP type-checking that agents edit accurately even without prior context. Forms for human-in-the-loop tasks (like buying a domain) deconstruct API requirements into validated inputs. Vite becomes the default build/dev server, and `cf migrate` moves Wrangler projects over, with maintenance support for Wrangler for 18 months after beta.
