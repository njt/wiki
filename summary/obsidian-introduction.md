# Introduction to Obsidian

Bryan Hogan's introduction to Obsidian as a note-taking application for knowledge work and personal notes.

## Why Obsidian?

Key advantages highlighted:

- **Local Files & Open Format**: Works with local markdown files, an open format usable across multiple applications
- **File Ownership**: Since files are stored locally, users maintain complete ownership and control, protecting against "enshittification"
- **Powerful Linking**: Enables creating interlinked content using `[[ ]]` syntax
- **Customization**: Allows personalization through plugins to match individual use cases
- **Community**: Benefits from a large, active user community
- **Cross-Platform**: Desktop and mobile versions offer equal feature sets

The author references the CEO's article on "file over app" philosophy and notes they've written a detailed Notion vs Obsidian comparison.

## Rules to Keep in Mind

Key advice:
- Avoid FOMO marketing anxiety when exploring features
- Set limits on customization exploration
- "Keep it simple. Obsidian should help you work on other things"
- Critically evaluate what features are actually needed

## How I Use Obsidian

Four primary use cases:

1. **Content Creation**: Blog posts and monthly email newsletters
2. **Knowledge Management**: Information collection and summarization using bottom-up approaches
3. **Project Management**: Personal projects and life tracking
4. **Media Tracking**: Books, video games, and YouTube videos (utilizing Obsidian Bases)

System approach:
- Avoids custom themes
- Minimizes plugin usage
- Uses core plugins built by Obsidian team rather than community plugins
- Implements a Zettelkasten and Evergreen notes system with bottom-up methodology

The author emphasizes flexibility, noting that simpler folder-based organization works fine if already functional.

## Syncing & Back-ups

Syncing method:
- Google Drive (Windows Desktop)
- DriveSync (Android)
- GitHub for periodic backups

References a detailed post comparing multiple syncing approaches.

## Graph-view & Canvas

Mixed reviews: Graph view, while visually appealing on social media, sees limited practical daily use. Canvas feature described as needing additional development and receives occasional use.

## Similar Tools

Tools the author uses:
- Notion: Collaborative content and database management (Kanban boards)
- Logseq: Daily journaling and short notes

Mentioned alternatives (not currently used): Capacities, Octarine, SilverBullet, SiYuan, AnyType, and Affine.
