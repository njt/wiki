Lovelace is a local-first, file-based project management desktop app for software teams that build with AI coding agents. All project state — tickets, documentation, ADRs, agent session records — lives as plain Markdown files with YAML frontmatter in `.lovelace/` inside the repo. A Tauri app (macOS/Linux/Windows) provides the UI; a bundled MCP server and hook system deeply integrates with Claude Code so agents read, mutate, and record work natively. The schema is user-editable in YAML and drives forms, validation, and indexing at runtime. AGPL-3.0, no server, no cloud, no account.
