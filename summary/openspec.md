Open-source, spec-driven framework serving as a universal planning layer for code development across multiple AI coding agents. No API keys or MCP integration required.

Core concept: specs live in your code alongside implementations, serving as persistent documentation beyond single chat sessions.

Intent-Based Review: generates spec deltas that capture how system requirements evolve. Reviewers understand intent rather than parsing implementation details.

Persistent Context: specifications organized by capability within repo structure. New developers understand system architecture through browsable documentation.

Rapid Proposal Generation: describe desired changes via agent commands, triggering automatic analysis of existing specs and codebase. Generates proposal documents, design decisions, implementation tasks, and requirement deltas before coding begins.

Integrates with 30+ coding platforms including Claude Code, Cursor, GitHub Copilot, Windsurf, Amazon Q.

Philosophy: minimal effort, lightweight process. "10 minutes thinking things through" before coding, while remaining flexible when requirements change.

Specs are version-controlled within repositories using standard git workflows. Framework creates specs incrementally as needed, not upfront for the entire codebase.

"Specs only work if you actually read them, think through them, and engage with them."
