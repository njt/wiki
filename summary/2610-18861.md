# Hybrid Reasoning Agents (arXiv 2610.18861)

An arXiv paper (submitted 13 Oct 2026, cs.CL) proposing **HybridAgents**: LLM agents that move fluidly between latent (vector-space) reasoning and text-based reasoning/tool interaction inside one unified generation process. A lightweight **HybridLink** module mediates transitions between the two modes, and a **continuous working memory** carries lossless hybrid context across multiple turns — so latent thoughts remain inspectable while tool access is preserved.

The paper also introduces dedicated post-training: **HybridSFT** first teaches the backbone to coordinate with HybridLink during tool-integrated hybrid generation, then **HybridRL** scales reasoning by learning *when* to think in latent space and when to act through text. Evaluated at 3 model scales across 11 benchmarks (math, science, medicine, search, agentic reasoning), HybridAgents reportedly beats frontier LLM agents and agentic frameworks by 10.4% on average while delivering 35.5–54.7% token reduction, 1.8–2.6× faster inference, and 2.7–3.7× cost savings. Code and data are released.

Key claims: latent reasoning is efficient but tool-blind; text reasoning is tool-native but verbose; the hybrid split lets the model do heavy internal thinking cheaply and only surface text when acting on the world.
