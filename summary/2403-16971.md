AIOS (arXiv 2403.16971, cs.OS, first posted March 2024, revised through August 2025) is an academic proposal to treat LLM agent serving as an operating-system problem. The authors argue that current agent designs let agents access LLM and tool resources without restriction, and lack scheduling and resource management, which blocks concurrent processing and wastes system efficiency.

Their answer is to split agent applications from an "AIOS kernel" that owns LLM-specific services: scheduling of agent requests, context/window management, memory management, storage management, and access control. An SDK exposes the kernel's functionality to agent applications. They report up to 2.1x faster execution serving agents built by various agent frameworks, with source code available.
