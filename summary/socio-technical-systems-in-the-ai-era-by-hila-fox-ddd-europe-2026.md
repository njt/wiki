# Socio-technical Systems in the AI Era

Hila Fox's DDD Europe 2026 talk (49 min) argues that AI agents are not tools
but **new socio-technical actors**, and that the industry's dominant failure
mode is "mirroring": building agents that automate the company's *existing*
processes — warts, informal networks, ego-driven approval loops and all —
rather than redesigning the process first.

Her five claims:

1. Agents are new socio-technical actors — artifact *and* reasoning, sitting
   between the human and non-human columns.
2. We are **automating our organizational illnesses** into agents ("write a
   Slack message to Tom because he gets defensive if left out"), producing
   agent silos, competing agents from rival VPs, and hierarchical power
   dynamics between agents.
3. **Context is queen** — the new building block of systems. The old stack of
   data / APIs / orchestration becomes context / MCP / agent-to-agent /
   workflows; pulling context apart exposes real team coupling.
4. Poorly designed context boundaries will produce **context hell**, like
   data lakes before them. Context is both organizational memory and the
   decision rationale, since the agent now holds the if/else.
5. Systems are changing and we must be flexible: command→intent,
   sequential→parallel, micromanagement→oversight, and the emerging "dark
   factory" of fully autonomous teams.

She closes with **defend, evolve, redesign**: keep the old-world
architecture discipline, evolve skills and human/agent role boundaries, and
redesign org structures around context coupling.
