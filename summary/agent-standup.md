Landing page for **Agent Standup**, a free open-source tool that renders a Claude Code session as a live standup meeting: the lead agent gives orders, sub-agents "join the call", share their screen, report status, and leave — complete with voices, custom characters, and 8 languages. The pitch line: "See who is waiting on whom and who is blocked, at zero token cost."

Distribution is deliberately low-friction: one small local server with a VSIX for Cursor/Windsurf/VSCodium, any terminal, a desktop app (unsigned), a Claude Code status-line indicator, and tmux. The only prerequisite is having used Claude Code on the machine at least once.

The page is self-aware about its own silliness. Asked "Is it serious?" it answers "Mostly for fun. No." and signs off as "Made by a bored dev and his robots." The feature list is real, though: per-agent status, context gauge and token counts, replay/recap/tree/video of the run.
