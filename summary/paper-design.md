Paper.design is the marketing landing page for Paper, "the connected canvas for teams shipping with agents" — a design tool built on web standards (HTML/CSS canvas) positioned around a continuous loop between design and code. Its pitch: connect any IDE or CLI agent to the canvas via MCP so agents can sync design tokens, styles and components between the codebase and the canvas, "one source of truth, always current."

The page's core claims: because the canvas *is* HTML/CSS, "your design exports as code — nothing gets lost in translation"; agents can pull real content from any app, file, CMS or database into design layers ("goodbye lorem ipsum"), and copy edited on the canvas can be written back into the codebase by the agent. The "anti-slop" section frames agent delegation as offloading boilerplate — responsive variants, style variations, consistency checks — so humans "focus on the decisions only you can make," with agents that "see your canvas" reading and writing "on the right foundations."

Announcements on the page: Paper Desktop (a "fully connected canvas" workflow), a roadmap, September 2026 quality/performance improvements and in-app agent setup, and a $34M Series A from Accel and ICONIQ to "build the next great design platform."
