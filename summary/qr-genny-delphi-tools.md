## QR Generator Tool

URL: https://delphi.tools/tools/qr-genny

Generates styled QR codes with custom colors, shapes, and logos. The interface offers extensive customization in a live-preview workflow.

### Modes
- Single (default card view)
- Batch Mode (for generating multiple codes at once)

### Content Types
The tool encodes: URL, Email, Phone, WiFi (credentials), SMS, Geo (geographic coordinates)

### Quick Styles
Six preset themes: Classic, Rounded, Dots, Classy, Indigo, Rose, Teal

### Export Formats
PNG, SVG, or Copy (to clipboard)

### Customization
- **Size:** 300px default
- **Padding:** 2 default
- **Error Correction:** L, M, Q, H levels
- **Bit Style shapes:** Boxy, Bouba, Braille, Calligraph, Kiki, Blobby
- **Eye shapes:** Boxy, Circular, Rounded
- **Pupil shapes:** Square, Circle
- **Colours:** Custom color selection
- **Logo/Image:** Embed option

### QR Code History
Invented by Masahiro Hara at Denso Wave in 1994. Original purpose: automotive tracking. Now ubiquitous for URLs, payments, and more.
