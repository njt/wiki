Spec-first approach: define each object once, in a way that any platform capability can consume. Instead of objects integrating with platform capabilities, objects declare their shape and behavior through a unified contract. This enables platform capabilities to read from that schema and operate generically across all objects that conform to it. The integration point moves from per-platform capability implementations to a single shared one.
