A single-page pattern registry of roughly one hundred named patterns for building agentic systems, generated from a curated `patterns/` source and filterable by dimension (context-engineering, orchestration, verification, workflow-discipline, tool-design, taste, human-factors, cost-routing, observability, reliability, meta-principles, knowledge, intent).

The patterns are compressed aphorisms, each a title plus one dense sentence with topic tags. They cluster around a few big ideas: context as the scarce resource (write, select, compress, isolate; thin pointers over full content; clean-slate delegation; scoped and expiring memory); verification as the load-bearing wall (agents fake "done", demand independent proof, evals as a standing capability, deterministic rails around model judgment); orchestration discipline (single-threaded linear agent by default, sub-agents as context sinks, separate the proposer from the authority); and the human factors (attention is the scarce resource, coaches and players, nontechnical owners only with guardrails).

Also notable: meta-principles about the practice itself — ablate the harness as models improve, invest the expensive model in the harness, build a pattern registry, repository shape is cognitive architecture — and intent-layer patterns like interviewing to a spec before implementing and the "good pile, bad pile" technique of collecting labeled examples instead of abstract rules.
