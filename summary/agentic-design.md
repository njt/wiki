Agentic Design is a free architecture catalog for building AI agents in
production. It offers 280+ patterns, 280+ techniques, 900+ use cases, and
280+ interactive demos — organized for inspection and comparison rather than
as a flat list of terms.

The core workflow walks builders from constraint (reliability, latency, cost,
safety) through pattern selection, implementation options, and hands-on
practice. The site also covers MCP, LLM models, benchmarks, fine-tuning,
inference, and a glossary.

Content is freely browsable under a freemium model. Pro unlocks full learning
journeys, a Prompt Optimizer, an Eval Lab, guided code challenges, red-team
audits, workshop tools, and managed AI usage (or bring-your-own API key).

The design philosophy stresses production reliability — reasoning, tool use,
and safe failure — with a disclaimer that example scenario figures are
illustrative, not performance or compliance guarantees. Produced by KORTEXYA
SAS, a French company.
