# AgentMail

AgentMail is an API-first email platform designed specifically for AI agents and automated workflows. It gives AI agents their own functional email inboxes through a REST API — analogous to what Gmail provides for humans. Built for two-way email communication in agentic scenarios (receiving 2FA codes, parsing invoices, replying to support threads), not just one-way notification sending like Mailgun or SendGrid.

## Features

- **Instant inbox creation** via a single API call, no domain verification or waiting period
- **Threads and replies** — real conversational exchanges, not isolated messages
- **Attachment handling** for parsing invoices, receipts, and documents
- **Semantic search** across messages
- **Real-time webhooks** for immediate agent reaction to incoming mail
- **Custom domains** for teams
- **SDKs and MCP support** with typed Python and TypeScript clients

## Use Cases

- Browser agents extracting OTP codes during signups
- Scheduling assistants managing calendars over email
- Document processors ingesting attachments
- Customer service agents routing support emails

## Infrastructure

- SOC 2 compliant
- Built on redundant multi-region infrastructure
- Tech stack: NodeJS, TypeScript, pnpm, Webpack, Biome JS, Vitest, GitHub Actions
