A manifesto-style paper arguing that large-scale agile (SAFe, LeSS) fails because it is human-centric and meeting-driven, and that AI agents should become first-class participants in the organization rather than per-developer tools. Its motto: "Human intent, machine velocity, where human experts direct and AI agents deliver."

## The values

Five value pairs in classic manifesto form: shared context and living knowledge over meetings and static documents; human intent and AI execution over manual role handoffs; parallel continuous verification over sequential phase gates; orchestrated AI workforces over isolated tool assistance; reusable blueprints with local adaptation over rigid frameworks.

## Six principles

1. **The new process** — planning, implementation and verification run in parallel because AI collapses the cost of each activity; remaining gates must be automatable checks, not approval meetings.
2. **The new teams** — engineers define intent and verify output rather than writing all the code; governance shifts from "Human in the Loop" (approve every step) to "Human in Control" (full authority without being the bottleneck), because post-hoc correction is cheap and per-step approval is expensive.
3. **The new artifacts** — static documents have "a half-life measured in weeks"; they are replaced by version-controlled, AI-ergonomic living specifications in a unified semantic layer that agents consume and update.
4. **The new assurance** — verification-first: tests generated from specs before code exists, BDD Given-When-Then as the shared definition of "correct", with agents managing scenario explosion at scale.
5. **The extended workforce** — a supervisor agent orchestrates role-based subagents (Persona / Agent / Skill constructs) with bounded contexts to defeat context overflow.
6. **The new reuse** — teams publish blueprints (personas, specs, skills, knowledge graphs) that other teams adapt locally: "reuse without rigidity."

## The blueprint and platform engineering

The AI-native blueprint combines BDD, parallel agile, and multi-agent collaboration over a semantic layer of four knowledge graphs (architecture, code, security, dev-intelligence) shared by humans and agent personas. Platform engineering becomes the bridge serving both human engineers and AI agents, with golden paths acting as guardrails for both audiences. Future directions include "dark software factories" where only agents code and new roles in agent orchestration, knowledge engineering, and AI governance.
