TEHAS is a live, self-hosted software factory dashboard built on the Pi coding agent and pi-rukas. The site's own summary: "The floor of a software factory powered by the Pi coding agent and pi-rukas. GitHub issues go in and reviewed pull requests come out, built in a sandbox on self-hosted models. A person merges."

The page is a JS-rendered control-room view, so most data ("Waiting for ticket data") doesn't render in the fetched text. What the static markup does show is the factory's line layout — four kanban stages: In Line / Next Up, Building / In Work, Review / Needs Review, Shipped / Latest — plus a Protolab section, a Production Console that looks for a running cycle, and an Energy Use panel with watt, 24-hour kWh and 30-day kWh figures for "serving the factory", backed by a host table (host, source, RAM) and a model table (model, hosts, engines, busy, queued).

There is also a Breakroom with a breakroom-arcade game, "Buzzword Buster", built from "the commonest words in the ticket titles, shuffled every round" — and the site is explicit that it is optional: "The score changes nothing on the line."

That is the whole of the static content. No essay, no write-up — the interest is in what the factory is, not in argument about it.
