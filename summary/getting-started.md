MotherDuck's getting-started page introduces the product in one sentence: a serverless cloud data warehouse built on DuckDB, with a "hypertenancy" architecture that gives every user or AI agent its own isolated compute instance — sub-second analytics, no infrastructure, no resource contention, lower cost. It positions three use cases: internal BI, customer-facing analytics in applications, and "agent-driven analytics tools."

The page is a landing/hub rather than deep documentation: it lays out six paths (an end-to-end tutorial, a data-warehousing overview, a customer-facing analytics overview built on MotherDuck's Wasm client, "Talk to Your Data with AI" via the remote MCP server, Dives — interactive dashboards generated from natural-language prompts, and Flights — scheduled Python jobs for pipelines), plus standard sections on connecting, loading data, and integrating with the modern data stack.

The AI angle is stated up front, not bolted on: isolated-per-agent compute and a remote MCP server are core product positioning, marking MotherDuck as a database built to be consumed by agents as much as by humans.
