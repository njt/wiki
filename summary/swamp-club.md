## Core Concepts (Building Blocks)

- **Models** — Zod schema-based typed interfaces validating incoming data
- **Workflows** — Multi-step directed acyclic graphs supporting parallel execution and nested composition
- **Data** — Immutable, versioned artifacts preserved from each execution
- **Vaults** — Encrypted credential storage referenced through expressions
- **Extensions** — Agent-created integrations that become fully functional system components
- **Reports** — Structured analysis in Markdown and JSON formats following every execution

| Before | After |

## How It Works

1. **INIT** — Framework auto-discovers capabilities
2. **BUILD** — Agent generates models from documentation
3. **COMPOSE & RUN** — Models integrate into workflows with YAML review and data versioning
