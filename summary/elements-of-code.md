By John Mark Wilkinson. A book that gives programmers a series of rules for writing software that future readers will understand.

Central philosophy: "Writing comprehensible code is what allows us to be wrong in correctable ways."

Perfect software is an impossible goal given constantly changing requirements and evolving contexts. The focus should be on creating code that can be corrected and adapted. Comprehensibility is the practical virtue that matters most.
