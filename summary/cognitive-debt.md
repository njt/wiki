# Cognitive Debt: When Velocity Exceeds Comprehension

## Core Argument
AI-assisted development creates a dangerous gap: code production velocity now exceeds human comprehension velocity. This creates "cognitive debt" -- a deficit in organizational understanding that remains invisible to traditional productivity metrics until system failures expose it.

## Key Arguments

**The Comprehension Lag**
Manual coding couples production with absorption -- the friction of typing forces engagement. AI decouples these processes. Developers can generate hundreds of lines instantly, but understanding cannot accelerate proportionally.

**Measurement Blindness**
Engineering metrics evolved assuming comprehension accompanied shipping. "Code works. Tests pass. Features ship. The deficit exists only in minds of engineers." Comprehension deficits remain unmeasured and therefore invisible to decision-makers.

**The Reviewer's Dilemma**
AI reverses the traditional code review dynamic. Previously, senior engineers reviewed slower junior engineer output. Now juniors generate code faster than seniors can audit it. Deep review becomes a bottleneck.

**Three Failure Modes**
1. Production code becomes increasingly dangerous over time
2. Incidents require investigation of unmaintained systems built by engineers long gone
3. Junior engineers never develop architectural intuition, depleting future leadership pipelines

**Organizational Memory Loss**
Tacit knowledge traditionally accumulated through implementation friction. When developers ship without deep comprehension, that knowledge never forms. "The organization loses knowledge not just through attrition but through insufficient formation."

## Notable Quotes
- "Code has become cheaper to produce than to perceive."
- "They are debugging a black box written by a black box."
- "The system is optimizing correctly for what it measures. What it measures no longer captures what matters."
