# Claude Artifact Server

A directory server hosting 22 interactive web-based artifacts generated by Claude, all created on 2026-03-29. The artifacts are themed with classic Macintosh (System 1-era) retro aesthetics and span database tools, debuggers, development environments, writing tools, research interfaces, productivity dashboards, and visual experiments.

The server lives at `artifacts.yolo.scapegoat.dev` and serves a simple catalog page with per-artifact descriptions, tags, file sizes, and format indicators (`.html` for standalone, `.jsx` for React-based). It includes client-side text filtering with the note: "First pass only: type to filter locally in the browser. A richer search UX can layer on top of the same search bundle later."

Artifacts are served from `/app/imports`.
