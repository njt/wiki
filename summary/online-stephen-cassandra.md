A staged, comic-illustrated AI Engineer San Francisco talk by Stephen Chin and Cassandra Chen (creator of Tracetune), framed as a story about "Alex" at the token factory who keeps burning tokens on failed pull requests. The core observation: AI-written PRs are rejected not because the code is bad but because the PR descriptions contain incorrect facts, generated by an agent that reads its own compressed session log — a context window that "gets more and more inaccurate as it goes along."

Tracetune (open source) fixes this by mining the agent's session traces across a machine to reconstruct what actually happened, then using an independent writer and reviewer to draft the PR from evidence rather than from the diff. Even this still made mistakes — the talk's worked example is a PR claiming tests passed while the trace shows a button test and `bunx tsc` running concurrently, which can't pass. Their first mitigation, cheaper writer models, made quality worse, not better.

The second fix is a graph. "Archie" — Relate, a new Rust embedded in-memory graph database — pre-computes an "evidence packet": a neighborhood brief connecting the why, the code, and the checks with attributions. The writer gets all connected facts with sources in one place and drafts accurately in fewer passes; cheap Haiku-class reviewers can then check the draft against the packet, while a Sonnet-class writer is retained. Counterintuitively, the writer is the higher-quality model and the reviewers are the cheap ones, because writing that "feels human-like" degrades to mechanical checklisting under a weaker model, while cross-checking is the mechanical task.

Results via PRBench (their side benchmark, run in parallel across models, judged by LLM judges and humans): judge scores improved from ~74→82 and ~76→86 on a 100-point scale across Claude and Codex, and token cost dropped roughly in half, because the evidence graph replaces expensive agent research loops. The generalizable claim: agents are bad at data analysis and curation; give them a pre-built graph layer and costs fall while quality rises.
