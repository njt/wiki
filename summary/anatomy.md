Ryan's write-up of Anatomy, a Claude Code skill that turns a one-line idea into a live isometric machine — not a boxes-and-arrows diagram, but an invented mechanical object whose moving parts *are* the concept (a queue is a marble run, a bloom filter is a fruit machine). The skill's single governing rule, "the object is the explanation," sits above everything else in its instructions.

The piece documents the skill's fixed ten-step pipeline (size → truth model → invent object → list parts → plan → build → paint → frame → animate → verify like a critic), and stresses that most quality is decided before any geometry exists. A "truth first" model drives both motion and readouts, so the numbers can never disagree with the picture. Figures ship as framework-free TypeScript/SVG, React components (npm package, five themes, 26 colour tokens), or custom elements; WebGL shaders and true 3D sit in layers on top.

Timing data is refreshingly honest: a watch movement took 1h54m in one pass, but the Raptor 2 engine took 10h33m and a turbofan 14h — a first working version arrives fast, and "most of the time goes into the second look." The skill never starts an Epic without asking, ships six examples it opens before starting, and the author's closing advice is to treat the first figure as a draft and iterate.
