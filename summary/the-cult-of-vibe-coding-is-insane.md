# The Cult Of Vibe Coding Is Insane

Bram Cohen (creator of BitTorrent) argues that the "vibe coding" philosophy—where developers refuse to look at or contribute to code produced by AI—is a counterproductive dogma that leads to knowingly poor software quality. He uses a recent leak of Claude's source code as his launching point.

## Key Arguments

**Dogfooding Taken Too Far:** Cohen frames the Claude code quality issues as "dogfooding run amok." He asserts that vibe coding's core premise—making "literally no contribution to what's going on under the hood"—is a myth. Developers still build "infrastructure" like plan files, skills, and rules; the machine "works very poorly without being given a framework."

**The Absurdity of Not Looking:** He finds it ridiculous that Claude's team apparently refused to inspect their own codebase for duplication. He notes the code is "written in English" and "anyone could read it," making the refusal to look a matter of ideology, not necessity.

**AI Is Actually Good at Cleanup:** Cohen argues that AI excels at refactoring and debt reduction. He contrasts this with historical software projects where cleanup would take a year, saying AI can now accomplish it "in sometimes a matter of weeks."

**The Human Role Is Critical:** Cohen emphasizes that the human must provide high-level guidance, correct the AI when it "sycophantically" agrees with wrong ideas, and clarify edge cases beforehand. The result *looks* like one-shotting but actually involves substantial back-and-forth.

## Key Quotes

- "Bad software is a decision you make."
- "Pure vibe coding is a myth."
- "Looking under the hood is cheating."
- "Projects are born in sin."

## Notable Comment Themes

- Chris Pirillo called Cohen's closing line "Quote of the millennium."
- Nimish Gåtam connected vibe coding extremism to a recurring pattern of "purity" advocacy in software development, comparing it to historical taboos like calling C from interpreted languages.
