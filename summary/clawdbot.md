# OpenClaw (formerly clawdBot): Personal AI Assistant

Note: clawd.bot now redirects to openclaw.ai.

## Purpose & Overview

OpenClaw is an open-source personal AI assistant that runs locally on users' machines (Mac, Windows, or Linux). It operates through chat applications like WhatsApp, Telegram, Discord, and Slack, enabling users to delegate tasks like email management, calendar organization, and information retrieval through natural conversation.

## Core Features

**Local Execution & Privacy**
Runs on your own hardware rather than cloud servers, keeping data private by default. Users can choose between Anthropic's Claude, OpenAI's models, or local alternatives.

**Multi-Platform Chat Integration**
Access through WhatsApp, Telegram, Discord, Slack, Signal, and iMessage—both in direct messages and group conversations.

**Persistent Memory**
Maintains contextual awareness across sessions, learning user preferences and building personalized understanding over time.

**Browser Automation**
Handles web browsing, form filling, and data extraction from websites independently.

**System-Level Access**
Manages files, executes shell commands, and runs scripts with configurable sandboxing options.

**Extensible Skills Framework**
Users can build custom capabilities or enable community-created plugins. The AI can write and modify its own skills.

## Installation
```
curl -fsSL https://openclaw.ai/install.sh | bash
```

## Key Differentiators

- Open-source and hackable rather than proprietary
- On-premise hosting with full user control
- Self-improving capability where the assistant develops new skills through conversation
- No subscription model beyond underlying AI service costs
- Community-driven development with shared skill repositories
