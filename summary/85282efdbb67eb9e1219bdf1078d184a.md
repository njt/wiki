Courtney Yatteau, a developer advocate at Esri and former high school teacher (10 years), presents three practical AI patterns for adding gamification to web applications. She argues against shallow gamification (meaningless points, disconnected badges, generic feedback) and for four pillars of good gamification: visible progress, relevant feedback, appropriate challenge, and meaningful reward.

The unifying mental model is **Signal → Decision → Response**: capture a simple user behaviour (click, answer, timing, reflection text), let AI make one focused decision (generate, classify, predict), and visibly change the UI (reward, feedback, difficulty shift). AI's role is deliberately small — "not tons of AI everywhere, just AI in places that we want it to feel more engaging for the users."

Three demos illustrate the pattern. **Dynamic Content** uses the OpenAI Responses API with strict structured output schemas to generate location-based facts and rewards tied to user context (place + vibe), with progressive unlocks (badges, map snapshots, DALL·E postcards). **Sentiment-Aware Feedback** uses Azure AI Sentiment Analysis on a single free-text reflection to choose a supportive or celebratory response tone. **Adaptive Challenge Tuning** uses a tiny TensorFlow.js model trained locally in the browser on correctness, response time, and current difficulty to predict the next challenge level — no server round-trip needed.

The combined geo-explorer app weaves all three patterns together with quiz challenges, mood check-ins, badges, map style unlocks, and a session recap. Notable omissions include cost and latency at scale, privacy considerations (especially relevant for a European conference), failure modes when AI calls fail, and empirical evidence of effectiveness.
