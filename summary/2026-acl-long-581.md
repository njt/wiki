An ACL 2026 long paper (Xiang et al.) on the economics of multi-agent systems: as applications move from one LLM call to multi-agent workflows with verification and testing steps, accuracy improves but latency and token cost balloon — and most queries never needed the heavy machinery in the first place.

The proposed system, LLM-as-Scheduler (LAS), dynamically picks the right workflow per query using a two-stage cascade: a lightweight gate first quickly evaluates each agent's output, then an LLM-based scheduler combines query features with those gate signals to make the finer-grained routing decision. The point is to spend the expensive fixed workflow only on queries that actually need it.

Reported results: 43% token reduction and 36%+ end-to-end latency reduction, at a cost of at most 1.4 percentage points of accuracy versus a strong fixed workflow. The paper's framing is essentially a cost/quality Pareto argument for adaptive orchestration — route, don't escalate everything — which puts it in the same family as confidence-gated routing and tiered-model schemes in production systems.
