# MobileVibe — Vibe anything from anywhere

Marketing/landing page for MobileVibe, a mobile app that connects your phone to your desktop computer to run AI coding agents (Claude Code, Codex, with Windsurf, Cline, Cursor coming soon) remotely. Your machine does the work; your phone is the control panel.

## Hero

**Tagline:** "Build anything from your phone."

**Value prop:** "Start tasks, monitor AI agents, and ship real work. Your machine does the work. You stay in control from anywhere."

Three bullet points: no setup complexity, works with your own coding environment, live in under 5 minutes.

## Quick Start

1. Connect your computer via a lightweight desktop connector
2. Open MobileVibe on your phone — machine appears instantly
3. Run your first task

## How It Works

1. Describe the task — "like talking to a senior engineer"
2. Your computer runs it — agents execute on your real machine
3. Review from anywhere — notifications, approvals, "Ship from bed"

## Competitive Positioning

"Everything else breaks. This doesn't."

Three alternatives contrasted:
- Remote desktop — "Slow. Laggy. Unusable on mobile."
- Cloud IDE — "Limited. Fake environment. Missing tools."
- AI chat — "Talks. Doesn't actually execute."

## Features

1. Full Claude Code + Codex support (Windsurf, Cline, Cursor coming soon)
2. Mobile-first editing with proper copy/paste and autocomplete
3. Build & ship iOS apps without a Mac; "The MobileVibe iOS app was built this way."
4. Push notifications for agent completion, questions, or approval needs
5. Full desktop access (real CPU, GPU, filesystem)
6. Powerful local automation via MCP servers (Playwright, Unity, Blender, Firecrock)
7. Cross-device sync with preserved session state
8. Smart auto-approve with configurable rules
9. Works with existing stack (VS Code, extensions, config, repos)

## Security

Three pillars:
- Runs on your machine — "Nothing in the cloud."
- You control access — approve every action, revoke anytime
- End-to-end encrypted — private phone-to-machine link
