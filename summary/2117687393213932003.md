Josh Rosen's survey of agent state machines — explicit states, events and transition rules that govern agent behaviour — argues that without one "you're completely at the mercy of the nondeterministic nature of models." The core move: the model may request actions or propose transitions, but the surrounding software decides what is permitted.

He maps four layers where state machines appear. **Inside the agent loop**: states like reasoning, executing tools, waiting for approval, error handling — Stately Agent uses XState to make harness behaviour a first-class machine. **Above the loop, for workflows**: execution graphs controlling sequences of activities, via LangGraph's StateGraph, Mastra's createWorkflow, or n8n's visual graphs; LangGraph adds checkpointing for durable execution. **Outside the agent, supervising multiple agents**: OpenAI's Symphony dispatches Codex sessions against an issue tracker; Pi Missions embeds dispatch/validate/advance tools in the Pi harness extension API — the machine governs work across runs while workers keep their autonomy. **On the work itself**: ThruWire models AI checkpoints with requirements, dependencies and validation evidence — work isn't accepted until dependencies complete, and agents choose *how* while the system judges *whether*.

Rosen then asks why developers keep hand-rolling state machines despite LangGraph/XState: simplicity (five bespoke states don't need a graph runtime), preserving an existing harness (Claude Code, Codex, Pi), and integration with existing databases, queues and schedulers. The trap: simple machines accrete checkpointing, locking, scheduling and recovery until you've rebuilt the framework you avoided. Implementations are usually small — state in JSON or a database, transitions as validating functions, wired to the harness via SDK/subprocess, harness extension, or an MCP server with `claim_task`/`complete_task` tools. He predicts deterministic scaffolding layers will become standard agent infrastructure as agents take on longer-running, more consequential work.
