# Textverified

Textverified provides temporary, real US mobile phone numbers backed by physical SIM cards (non-VoIP) for receiving SMS verification codes and voice call verifications. Covers 900+ services (Google, Tinder, PayPal, Uber, Discord, WhatsApp, Amazon, etc.).

## How It Works
1. Register a free account
2. Purchase credits
3. Choose a service from 900+ supported options
4. Get a number immediately to receive a verification code
5. Pay per use via credit system

## Tiers
- **Verifications** (one-time): From $0.25/use — single SMS OTP or voice call, short-term reuse possible, US area code selection
- **Non-Renewable Rentals** (1–14 days): From $1.50/rental — unlimited SMS verifications on one number during period
- **Renewable Rentals** (ongoing): From $5/month — keep indefinitely with 30-day renewal, area code selection

## Key Differentiator
Numbers are carrier-based (physical SIM cards), not VoIP (like Google Voice). Services that block virtual numbers accept these.

## Payment
- Credit/debit cards (Stripe: Visa, Mastercard, Amex)
- Cryptocurrencies: Bitcoin, Ethereum, Litecoin, USDC, Tether, Monero
