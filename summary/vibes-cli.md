# VibesOS (vibes-cli)

GUI framework for Claude Code designed to simplify creation of small multiplayer web applications without requiring backend infrastructure. Collapses application code and state into single HTML files.

## Key Features
- Single-file HTML apps with embedded JavaScript and TinyBase database
- Local-first data storage with automatic cross-user synchronization
- No server setup or schema imports required
- Offline functionality with WebSocket relay sync
- Shareable via simple links for instant multi-user access
- Data encryption and portability in the browser

## Data Architecture
Uses TinyBase for reactive local-first applications with offline-first design, real-time collaboration syncing, and portable table/row data models.

## Notable Quotes
"AI doesn't make apps - it makes *text*." (explains design philosophy of embedding databases in JavaScript)
"The constraint is the feature" (referencing inability to run cross-tenant queries, positioning as groupware rather than platform)

## Deployment Options
- Desktop app (macOS)
- Claude Code plugin via marketplace
- Skills for AI-assisted generation (`/vibes` command)
- Launch command for end-to-end SaaS deployment
